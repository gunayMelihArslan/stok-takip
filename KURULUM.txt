KURULUM KILAVUZU — Tarayıcıdan, komut satırı yok
═════════════════════════════════════════════════
Toplam süre: ~15 dakika. Bir kez yapılır, bir daha uğraşılmaz.


ADIM 1 — GitHub hesabı aç (2 dk)
──────────────────────────────────
1. github.com → "Sign up"
2. E-posta + şifre + kullanıcı adı
3. Ücretsiz plan seç → Bitti


ADIM 2 — Repo oluştur ve dosyaları yükle (5 dk)
─────────────────────────────────────────────────
1. github.com'da sağ üstte "+" → "New repository"
2. Repository name: stok-takip
3. Private seç (gizli olsun)
4. "Create repository" tıkla
5. Açılan sayfada "uploading an existing file" linkine tıkla
6. stok-cloud.zip'i açıp İÇİNDEKİ dosyaları (stok-cloud klasörü değil,
   içindeki her şeyi) sürükle bırak oraya
7. Altta "Commit changes" → yeşil butona bas


ADIM 3 — Render.com'da Veritabanı Oluştur (5 dk)
────────────────────────────────────────────────
1. render.com → "Get Started for Free" tıklayıp GitHub hesabınızla giriş yapın.
2. Dashboard'da üstten "New" → "PostgreSQL" seçin.
3. Name: `stok-db`
4. Region: `Frankfurt (EU Central)` (Size en yakın olanı seçin)
5. Sayfanın en altındaki "Create Database" butonuna tıklayın.
6. Veritabanı oluşturulurken "Internal Database URL" (iç bağlantı) ve "External Database URL" adresleri görünecektir. Bu sekmeyi açık bırakın, birazdan lazım olacak.


ADIM 4 — Render.com'da Web Uygulamasını Yayınla (5 dk)
─────────────────────────────────────────────────────
1. Render dashboard'unda sağ üstten "New" → "Web Service" seçin.
2. "Build and deploy from a Git repository" seçeneğine tıklayıp "Next" deyin.
3. GitHub'daki `stok-takip` deponuzu bulun ve "Connect" tıklayın.
4. Name: `stok-takip-uygulamasi` (istediğiniz ismi verebilirsiniz)
5. Region: Frankfurt
6. Branch: `main`
7. Runtime: `Node`
8. Build Command: `npm install`
9. Start Command: `node server.js`
10. Sayfayı aşağı kaydırın, "Environment Variables" (Ortam Değişkenleri) bölümünü bulun. "Add Environment Variable" butonuna iki kez tıklayın:
    - 1. Değişken: 
      Key: `DATABASE_URL` 
      Value: (Bir önceki adımda oluşturduğunuz veritabanının `Internal Database URL` adresini kopyalayıp buraya yapıştırın)
    - 2. Değişken:
      Key: `JWT_SECRET`
      Value: (Rastgele uzun bir şifre girin, örn: stok_gizli_anahtar_99!)
11. En alttan "Create Web Service" butonuna tıklayın. Uygulamanız yüklenmeye başlayacaktır.


ADIM 5 — Kendi Domaininizi Eklemek (Opsiyonel)
────────────────────────────────────────────────
Eğer kendi alan adınızı (örn: stok.firmaniz.com) kullanmak isterseniz:
1. Render'da "Web Service" sayfanızdayken sol menüden "Settings" (Ayarlar) sekmesine gidin.
2. Sayfayı aşağı kaydırıp "Custom Domains" bölümünü bulun ve "Add Custom Domain" butonuna tıklayın.
3. Alan adınızı (örn: stok.firmaniz.com) girin ve kaydedin.
4. Render size bir CNAME hedefi (target) adresi verecektir (örn: `stok-takip.onrender.com`).
5. Domain aldığınız yerden (GoDaddy, Natro, Turhost vb.) DNS ayarlarına girin.
6. Yeni bir "CNAME" kaydı oluşturun ve hedef olarak Render'ın verdiği adresi yapıştırın.
7. Render otomatik olarak SSL (HTTPS) sertifikasını kuracaktır!


ADIM 6 — Adresini Al ve Kullanmaya Başla
──────────────────────────────────────────
1. Kendi domaininizi bağlamadıysanız, Render projenizin en üstünde sol tarafta kendi verdiği ücretsiz adresi göreceksiniz (örn: `https://stok-takip-abc1.onrender.com`).
2. Bu adresi tarayıcınızda açıp kullanmaya başlayabilirsiniz.
3. İlk Giriş: `admin` / `admin123`
   (Admin panelinden hemen şifreyi değiştirin!)

──────────────────────────
