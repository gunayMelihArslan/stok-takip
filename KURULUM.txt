=====================================================
 STOK TAKİP & ENVANTER YÖNETİM SİSTEMİ (v2.0)
=====================================================

1. GEREKSİNİMLER:
   - Node.js (v18 veya üzeri)
   - npm

2. KURULUM ADIMLARI:
   a) Proje klasörünü açın ve terminali başlatın.
   b) Bağımlılıkları yükleyin:
      npm install

   c) .env dosyasını oluşturun:
      .env.example dosyasının adını .env olarak değiştirin veya kopyalayın.
      Gerekirse JWT_SECRET ve PORT ayarlarını düzenleyin.

3. ÇALIŞTIRMA:
   - Geliştirici modu:
     npm run dev
   - Canlı (Production) modu:
     npm start
